# Crumb

Авторская витрина пекарни на React, TypeScript и Vite.

```sh
npm install
npm run dev
```

Откройте адрес `Local` из терминала. Если 5173 занят, Vite выберет следующий свободный порт.

```sh
npm run build
npm run preview
```

## Визуальное направление

Campaign: кобальтовая типографика, холодный фотографический фон, крупный wordmark и предметная съёмка без прямоугольных подложек. Unbounded используется для бренда, Golos Text — для русского текста и управления. Каталог построен как открытая витрина с разным масштабом товаров, а не одинаковые карточки.

Три работающих концептуальных прототипа доступны в dev-режиме:

- `/design/concepts/a.html` — Campaign
- `/design/concepts/b.html` — Journal
- `/design/concepts/c.html` — Gallery
- `/design/concepts/index.html` — сравнение

Исходные исследования и решение: `design/concepts/PLAN.md`, `COMPARISON.md`. Прототипы не входят в production-сборку. Итоговая дизайн-система: `DESIGN.md` и `.impeccable/design.json`.

## Функциональность

Категории, описание и аллергены, сохранение корзины в localStorage, количество 1–20, удаление, пустое состояние. Демонстрационный предзаказ с валидацией имени, датой/временем самовывоза и скачиванием текстового списка. Нативные диалоги удерживают фокус и закрываются по Escape. Движение учитывает prefers-reduced-motion.

Это концепция пекарни: продукты, цены и история иллюстративны. Платёж и отправка заказа отсутствуют. Имя не передаётся наружу и не хранится в localStorage; сохраняются только идентификаторы и количество продуктов.

## Фотография

Пять согласованных фотографий созданы встроенным OpenAI image_gen с настоящей прозрачностью. Производственные WebP: `public/images/v2/`; точные prompts/источники — `provenance.json` и боковые файлы `*.webp.json`. Исходные PNG: `design/photography/`. Повторная оптимизация: `node scripts/prepare-images.mjs` (после запуска сохраняйте provenance-sidecars). Шрифты размещены локально, OFL-лицензии в `public/fonts/licenses/`.

## Проверка

Сайт проверен в реальном браузере через CUA на 1440×1000, 768×1024, 390×844 и 320×740, включая каталог, корзину и весь демонстрационный сценарий. Скриншоты и отчёт в локальном `qa/redesign/` (не включены в сборку). Итог независимого аудита — `design/REVIEW.md`.
