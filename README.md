# Crumb

Авторская концепция сайта пекарни. React 19, TypeScript, Vite, Lucide. Шрифты Prata и Manrope размещены локально.

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Что работает

Категории каталога, описание товара и аллергены, корзина с локальным сохранением, количество от 1 до 20, удаление и пустое состояние. Демонстрационное оформление с выбором дня и времени самовывоза, валидацией имени и скачиванием текстового списка. Мобильная навигация и FAQ. Нативные диалоги удерживают клавиатурный фокус и закрываются по Escape. Анимации учитывают prefers-reduced-motion.

## Границы демо

Пекарня, товары, цены и история иллюстративны. Оплата, внешняя отправка заказов и серверная обработка не подключены. Сайт прямо сообщает об этом при оформлении и в подвале. Имя не хранится в localStorage и не передаётся наружу. В localStorage сохраняются только идентификаторы товаров и количество.

## Проверка

Визуально проверено через CUA в настоящем браузере на 1440×1000, 768×1024, 390×844 и 320×740. Скриншоты и независимый обзор находятся в `qa/` (не входят в сборку).

Через браузер проверены: меню, фильтрация, состав, количество, суммы, сохранение после перезагрузки, удаление, пустая корзина, ошибка формы, выбор самовывоза, скачивание списка и FAQ. Сборка включает строгую проверку TypeScript.

## Ресурсы

Главная фотография: встроенный OpenAI image_gen. Точный prompt и источники фотографий: `public/images/provenance.json`. Лицензии шрифтов: `public/fonts/licenses/`.
